# Model manifest for the leakage-safe grid: 16 models / 7 architectures.
# scripts/deploy_grouped_grid.sh reads this file (one HF model id per line;
# '#' starts a comment; blank lines ignored). Comment out rows to run a subset --
# the runners pass --skip-existing, so partial/interrupted runs resume cleanly.
#
# All chosen to fit a 48GB A6000 in bf16 (dense <= ~14B; OLMoE MoE = 7B total).
# Sizes >= 27B (Gemma-2-27B, OLMo-2-32B, OLMo-3-32B) and big MoEs (Qwen3-30B-A3B,
# Gemma-4-26B) are OMITTED -- they exceed 48GB in bf16 (would need quantization).
# Verify each id resolves on HF before a big run; gated rows (Llama, Gemma) need
# HF_TOKEN in .env.deploy + accepted licenses on the model's HuggingFace page.
# Open rows (Qwen, Phi, OLMo, OLMoE) need no token.
#
# NOTE (release): in the authors' working copy most rows were commented out after
# they had been run; all 16 are enabled here so a third party reproduces the full
# grid in one pass.
